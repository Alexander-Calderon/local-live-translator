# Security

The web app binds to the local loopback interface. Its session URL is private. Controls require the local origin and a control header. Do not expose the server through a public proxy.

Saving transcripts is optional. Saved files contain speech and may include private information. Review them before sharing.

For a security issue, use the repository's private vulnerability reporting option when available. Do not put recordings, tokens or private session URLs in a public issue. Describe the affected component and the steps to reproduce with synthetic data.

This is a beta project. The publication checker catches selected patterns and unexpected files; review the diff yourself before publishing.
